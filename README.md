PhyloGuard: Automated Sequence & Phylogenetic Analysis

PhyloGuard is a Python-based bioinformatics project designed to integrate DNA sequence analysis into a user-friendly Streamlit application.

 Objectives
- Validate FASTA sequence inputs.
- Analyse sequence length and nucleotide composition.
- Compare sequence similarity and identify variations.
- Examine multiple sequence alignments.
- Support phylogenetic analysis and sequence classification.

 Technologies Used
- Python
- Streamlit
- Biopython
- Pandas
- NumPy
- Matplotlib
- Google Colab

 Project Files
- `app.py` — Main Streamlit application.
- `requirements.txt` — Required Python packages.

 Installation

Install the dependencies:

bash
pip install -r requirements.txt


 Run Locally

bash
streamlit run app.py


 Academic Context

Developed as a B.Tech Biotechnology/Bioinformatics team project. PhyloGuard integrates established bioinformatics methods into a unified application rather than claiming to invent the underlying algorithms.

Note: The features available depend on the modules implemented in the current version of the application.
